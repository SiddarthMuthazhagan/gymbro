# 💪 GymBro — Gym Workout Ledger

> **Track your workouts. See your progress. Build consistency.**

GymBro is a modern workout-tracking web application designed to make gym logging simple, structured, and motivating.

Instead of relying on scattered notes or trying to remember previous workouts, GymBro provides a centralized place to record training sessions, monitor progress, and review performance over time.

---

## ✨ Features

* 🏋️ **Workout Logging**
  Record exercises, sets, repetitions, and weights in a structured format.

* 📊 **Progress Tracking**
  Visualize training performance and monitor improvements over time.

* 📅 **Workout Organization**
  Keep your training sessions organized instead of digging through phone notes like an archaeologist.

* 📈 **Performance Analytics**
  Use charts and visual summaries to understand your training progress.

* 🎯 **Goal-Oriented Training**
  Keep your workouts focused around measurable progress.

* 📱 **Responsive Interface**
  Designed to provide a clean experience across different screen sizes.

* 🎨 **Modern UI**
  Built with a component-based interface and a clean fitness-focused design.

---

## 🧠 Why GymBro?

Many people track their workouts using notes, spreadsheets, or memory.

That works... until you need to remember what weight you used three weeks ago.

GymBro was created to make workout tracking:

**Simple → Structured → Measurable → Consistent**

The goal is not to make fitness unnecessarily complicated. It is to make logging workouts easy enough that you actually keep doing it.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/SiddarthMuthazhagan/gymbro.git
```

### 2. Enter the project directory

```bash
cd gymbro
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Vite will start the local development server and provide a URL to open the application in your browser.

---

## 📦 Build for Production

Create a production build with:

```bash
npm run build
```

The optimized production files will be generated by Vite.
